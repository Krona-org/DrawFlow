# K1804 Microcode Editor (v3.0.0)

Современный графический редактор схем и визуальный отладчик микропрограмм для отечественного секционного микропроцессорного комплекта серии **К1804** (аналог **AMD Am2900**).

Программа позволяет проектировать алгоритмы микропрограммного управления на визуальном холсте, настраивать параметры полей **M1–M15** через интерактивный диалог и экспортировать прошивки в бинарные и текстовые файлы для эмулятора **1804.EXE**.

---

## 🚀 Быстрый запуск и установка

Готовая сборка со всеми библиотеками Qt6 и компилятора MinGW находится в папке `dist/`:

### Вариант 1: Запуск без установки (Portable)
Перейдите в папку:
```
dist/K1804Editor/K1804Editor.exe
```
Просто запустите файл `K1804Editor.exe` — всё необходимое окружение (Qt6, плагины платформ, стили и шрифты) уже упаковано в каталог.

Также в папке `dist/` сформирован готовый архив для переноса на любой другой компьютер:
* **`dist/K1804Editor-v3.0.0-win64.zip`** (портативная версия, распакуйте и запускайте).

### Вариант 2: Установка в систему (с ярлыками на Рабочем столе и в Пуск)
1. Откройте папку `dist/`.
2. Запустите двойным кликом **`Install.bat`**.
3. Скрипт автоматически установит программу в `%LOCALAPPDATA%\Programs\K1804Editor` и создаст удобные ярлыки:
   - **На Рабочем столе:** `K1804 Editor`
   - **В меню «Пуск»:** `K1804 Editor`

## 🛠 Возможности программы

* **Интерактивный холст микропрограммы:**
  - Добавление блоков микрокоманд (`MasterBlock`), начальных/конечных меток и комментариев.
  - Соединение блоков ортогональными линиями связи со стрелками.
  - Масштабирование, панорамирование, плавная прокрутка и сетка выравнивания.
* **Редактор параметров микрокоманды (M1 – M15):**
  - **Группа 1:** Управление переходами и адресацией (**К1804ВУ1**) — поля `M1`, `M4`, `M3`, `M2`.
  - **Группа 2:** Арифметико-логическое устройство (**К1804ВС1**) — поля `M5`, `M6`, `M9`, `M10`, `M8`, `M7`, `M11`.
  - **Группа 3:** Регистр признаков и состояния (**PSW**) — поле `M13`.
  - **Группа 4:** Входные шины данных и внешние стробы — поля `M12`, `M14`, `M15`.
  - Автоматическая валидация восьмеричных адресов (000..177777 oct) и предотвращение конфликтов адресов в ПЗУ.
  - Автоматическая генерация 6 строк мнемосхемы внутри каждого блока.
* **Интерактивный справочник (F1):**
  - Доступен из меню `Помощь -> Справочник микрокоманд (F1)` или по кнопке `«Справка...»` в редакторе блока.
  - Содержит вкладки с подробными таблицами всех 15 полей и живыми примерами типовых алгоритмов (сложение, вычитание в доп. коде, загрузка констант, условные переходы по флагам нуля/переноса, микроподпрограммы).
* **Экспорт и совместимость:**
  - Экспорт в `.PZU` / `.BIN` для прямого запуска в оригинальном DOS/эмуляторе **1804.EXE**.
  - Сохранение и загрузка схем в структурированном XML-формате (`v3.0`).

## 💻 Сборка из исходного кода

### Требования
* **ОС:** Windows 10 / 11 (64-bit)
* **Qt:** Qt 6.5+ (Qt6Core, Qt6Gui, Qt6Widgets, Qt6Xml, Qt6Svg)
* **Компилятор:** MinGW 64-bit (GCC 13+) или MSVC 2022
* **Система сборки:** CMake 3.20+ и Ninja

### Команды сборки (Release)
```powershell
# Конфигурация проекта
cmake -B build-release -S . -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/6.10.2/mingw_64"

# Компиляция
cmake --build build-release --config Release
```

### Развертывание зависимостей через windeployqt
```powershell
C:\Qt\6.10.2\mingw_64\bin\windeployqt.exe --compiler-runtime --release --no-translations dist/K1804Editor/K1804Editor.exe
```
