# DrawFlow

**DrawFlow** — графический редактор схем алгоритмов и интерактивная среда проектирования микропрограмм для секционных микропроцессоров серии **К1804** (отечественный аналог **AMD Am2900**).

Программа позволяет визуально проектировать микропрограммы на холсте с помощью блоков (`MasterBlock`), настраивать все 15 полей микрокоманды (**M1–M15**) и экспортировать прошивки в форматы `.BIN` / `.PZU` для эмулятора **1804.EXE**.

---

## 🚀 Быстрый запуск и установка

Готовый дистрибутив Windows находится в каталоге `dist/`:

### 1. Портативная версия (без установки)
* Перейдите в папку:
  ```
  dist/DrawFlow/DrawFlow.exe
  ```
* Запустите **`DrawFlow.exe`** — программа запустится сразу (в чистом оконном режиме без черного окна консоли). Все необходимые DLL и плагины Qt6 уже находятся рядом.
* Для переноса на другой ПК используйте готовый архив:
  - **`dist/DrawFlow-win64.zip`**

### 2. Установка в систему (с ярлыками)
1. Откройте папку `dist/`.
2. Запустите файл **`Install.bat`**.
3. Программа установится в профиль пользователя (`%LOCALAPPDATA%\Programs\DrawFlow`) и автоматически создаст ярлыки:
   - **На Рабочем столе:** `DrawFlow`
   - **В меню «Пуск»:** `DrawFlow`

## 🛠 Возможности

* **Графический холст DrawFlow:**
  - Создание и связывание блоков ортогональными линиями связи со стрелками.
  - Масштабирование, панорамирование, плавная прокрутка и координатная сетка.
* **Редактор микрокоманд К1804 (поля M1 – M15):**
  - **Группа 1:** Управление переходами и адресацией (**К1804ВУ1**) — поля `M1`, `M4`, `M3`, `M2`.
  - **Группа 2:** Арифметико-логическое устройство (**К1804ВС1**) — поля `M5`, `M6`, `M9`, `M10`, `M8`, `M7`, `M11`.
  - **Группа 3:** Регистр признаков и состояния (**PSW**) — поле `M13`.
  - **Группа 4:** Шины данных и внешние сигналы — поля `M12`, `M14`, `M15`.
  - Автоматическая проверка уникальности адресов ячеек ПЗУ (000..177777 oct).
  - Автоматическая генерация мнемокода внутри каждого блока.
* **Интерактивный справочник (F1):**
  - Полное описание каждого поля и режима с наглядными таблицами.
  - Готовые примеры типовых операций (сложение, вычитание, загрузка констант, условные переходы, подпрограммы).
* **Экспорт:**
  - Генерация двоичного дампа памяти ПЗУ (`.BIN` / `.PZU`) для эмулятора микропроцессора `1804.EXE`.
  - Сохранение проекта схемы в структурированный XML (`v3.0`).

## 💻 Сборка из исходников

### Требования
* Windows 10 / 11 (64-bit)
* Qt 6.5+ (Qt6Core, Qt6Gui, Qt6Widgets, Qt6Xml, Qt6Svg)
* MinGW 64-bit (GCC 13+) или MSVC 2022
* CMake 3.20+ и Ninja

### Сборка
```powershell
# Конфигурация CMake в режиме чистого GUI-приложения (без консоли)
cmake -B build-release -S . -G "Ninja" -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH="C:/Qt/6.10.2/mingw_64"

# Сборка исполняемого файла
cmake --build build-release --config Release
```

### Развертывание библиотек через windeployqt
```powershell
C:\Qt\6.10.2\mingw_64\bin\windeployqt.exe --compiler-runtime --release --no-translations dist/DrawFlow/DrawFlow.exe
```
